# ИДЗ 4 — Реверс-инжиниринг ELF-бинарника

Вариант 9. Мальцев Ф.А., группа 722-1.

## Описание

Реверс-инжиниринг ELF-бинарника с помощью утилит `file`, `readelf`, `strings`, `objdump`. Восстановлен исходный код на C.

## Файлы

- `base` — исходный ELF-бинарник
- - `reconstructed.c` — восстановленный исходный код
 
  - ## Сборка и запуск
 
  - ```bash
    gcc -o base_restored reconstructed.c
    ./base_restored 1
    ```

    ## Способ активации

    Передать аргумент `1` при запуске: `./base 1`
